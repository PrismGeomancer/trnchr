# $TRENCHER — 99 Day Simulator

A browser-based pixel-art strategy game about surviving 99 fictional days in the crypto trenches.

Start with a $2,500 simulated bankroll, scan fictional launches, read a small set of market clues, size positions, manage exits, earn reputation, unlock achievements and upgrades, and survive a complete 99-day run. Progress is saved locally on the player's device. No wallet, real token, or real-money trading is involved.

## Run locally

Serve the project root with any static file server, then open `index.html`.

```sh
python3 -m http.server 4173
```

Visit `http://localhost:4173`.

## Controls

- Use the on-screen controls for the complete game.
- Press `B` to enter a trade.
- Press `S` to exit an open position.
- Sound can be disabled from the top-right control.

The previous CodePen-derived prototype remains in `src/` and `dist/` for reference. The rebuilt game is served from the project root.

## Disclaimer

All tokens, prices, events, and outcomes are fictional. This project is entertainment, not financial advice.
